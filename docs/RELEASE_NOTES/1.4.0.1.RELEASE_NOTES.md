# BlockProt Reloaded Legacy 1.4.0.1 Release Notes

Welcome to BlockProt Reloaded Legacy 1.4.0.1, the first release of the edition for Minecraft 1.20.5 to 1.21.6. It carries the fixes and changes of BlockProt Reloaded 1.3.9 to servers that cannot move to Minecraft 1.21.7 yet.

## Highlights

- **Its Own Edition**: BlockProt Reloaded Legacy covers Minecraft 1.20.5 through 1.21.6 on Java 21. Servers on Minecraft 1.21.7 and newer use BlockProt Reloaded, and servers on 1.18.2 to 1.20.4 use BlockProt Legacy. The [version guide](https://github.com/VictorGugug/BlockProt-Reloaded/blob/main/docs/READ_MEs/VERSION_GUIDE.md) explains which one to download.
- **Chest Menus Only**: native Paper dialogs need the Paper 1.21.7 API, so this edition opens every menu as a chest inventory. The `use_dialogs` setting has no effect here and stays in `config.yml` so a later move to BlockProt Reloaded activates it.
- **Same Data, Safe Moves**: all editions share the plugin data folder and never rewrite keys they do not know. The plugin records the edition in `plugins/BlockProtReloaded/.edition` and makes a backup named with both editions when you move between them.
- **Correct Statistics After Transfers**: transferring a block moves it from the old owner's statistics to the new owner's instead of counting it for both.

## Changelog

### Added
- Added the edition model shown in `/bp about`, the boot banner and `/bp debug`.
- Added a startup warning on Minecraft versions newer than 1.21.6 that names the edition for that version and links the version guide. The plugin keeps running.
- Added a startup message on Minecraft versions older than 1.20.5 that disables the plugin, tells you to read the version guide and names the edition to download.
- Added console diagnostics checks for the edition marker and for statistics after ownership transfers.

### Changed
- Every paged chest menu now uses the same bottom row as BlockProt Reloaded: previous page, the menu's main action, and next page in the center, with Back in the corner. List menus show 45 entries per page.
- Update checks only offer releases of this edition (tags starting with `bprl-`).
- Updated Caffeine to 3.3.0, Apache Commons Lang to 3.20.0, and the Floodgate API to 2.2.5.
- Every console line, the first start guide and the debug reports now carry the name of the running edition instead of BlockProt Reloaded.

### Fixed
- Fixed transferred blocks staying in the previous owner's statistics and increasing the global protected block count on every transfer.
- Fixed transfers leaving the previous owner recorded in the database block index.
- Fixed the statistics list hiding the Previous button on its last page.
- Fixed the entity information menu drawing friends over its navigation row when an entity had more than 36 friends.
- Fixed clicks on empty bottom-row slots of list menus selecting an entry from the page.

## Not Included

- **Native Paper dialogs**: not available in this edition, see Highlights.
- **New features**: legacy editions receive bug fixes, security fixes and compatibility with new Minecraft releases inside their range. New features land in BlockProt Reloaded only.

## Availability

- **Modrinth only**: BlockProt Reloaded Legacy 1.4.0.1 is published on [Modrinth](https://modrinth.com/plugin/blockprot-reloaded-legacy) and as a GitHub release. It is not published on CurseForge or Hangar.
