# BlockProt Reloaded 1.4.1-hotfix.2 Release Notes

> **Note:** As a targeted maintenance release, this hotfix does not include a release notes banner.

1.4.1-hotfix.2 fixes locked blocks losing their protection after a server restart. No configuration or data format changes.

## Fixed

- **Hoppers drained locked chests after a restart** ([#22](https://github.com/VictorGugug/BlockProt-Reloaded/issues/22)): the list of protected blocks was rebuilt at startup from a background thread and only from the statistics file, so locks that were not found stayed unprotected until they were locked again. A hopper under a locked chest could then pull its items. Protection is now verified against the block itself whenever a location is not yet known.
- **Same cause, other protections**: after a restart, locked blocks were also exposed to pistons, explosions, fire, redstone, and block breaking by other players. They all use the same check and are fixed together.
- **Double chests**: the second half of a locked double chest was never registered as protected. It is now verified like any other block.
