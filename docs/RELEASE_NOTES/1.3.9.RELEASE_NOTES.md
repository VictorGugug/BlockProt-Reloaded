# BlockProt Reloaded 1.3.9 Release Notes

Welcome to BlockProt Reloaded 1.3.9. This release raises the minimum Minecraft version to 1.21.7, so native Paper dialogs are always available and are now built directly into the plugin, gives every paged chest menu the same button layout as the dialogs, and fixes statistics after ownership transfers.

## Highlights

- **Minecraft 1.21.7 Baseline**: 1.3.9 supports Minecraft 1.21.7 through 26.3. Servers on 1.21.1 to 1.21.6 keep using BlockProt Reloaded 1.3.8, and servers on 1.20.5 to 1.21 keep using 1.3.7; starting 1.3.9 on an older version shows which release to use and disables the plugin.
- **Dialogs Built In**: Paper dialogs are compiled directly into the plugin instead of being loaded through reflection from a separate build.
- **Consistent Chest Menus**: every paged chest menu now uses the same bottom row as the dialogs: previous page, the menu's main action, and next page in the center, with Back in the corner.
- **Correct Statistics After Transfers**: transferring a block now moves it from the old owner's statistics to the new owner's instead of counting it for both.
- **Editions**: BlockProt now ships as three editions, each with its own Minecraft range. The plugin knows which edition it is and points servers on another Minecraft version to the right download. See the [version guide](https://github.com/VictorGugug/BlockProt-Reloaded/blob/main/docs/READ_MEs/VERSION_GUIDE.md).

## Changelog

### Changed
- Raised the minimum supported Minecraft version to 1.21.7.
- Compiled the Paper dialog bridge into the main plugin and removed its separate source set and reflection loading.
- Moved Previous, Next, and the main action of every paged chest menu to slots 48, 50, and 49, with Back or Close in slot 53. List menus now show 45 entries per page.
- Updated Caffeine to 3.3.0, Apache Commons Lang to 3.20.0, and the Floodgate API to 2.2.5.
- Removed the typed inventory view fallback warning and the chest boat type fallback, which only applied to versions older than 1.21.7.
- The plugin JAR name now comes from the `jarBaseName` build property instead of the git branch name, and the Hangar platform versions are read from the `# Supported on` line of `gradle.properties`.
- Particle and enchantment constants that were renamed between Minecraft releases are resolved by name again, so the same code compiles against older Paper APIs.
- The unsupported Minecraft message now names the edition to download, its Minecraft range, and the download and guide links.

### Fixed
- Fixed transferred blocks staying in the previous owner's statistics and increasing the global protected block count on every transfer.
- Fixed transfers leaving the previous owner recorded in the database block index.
- Fixed the statistics list hiding the Previous button on its last page.
- Fixed the entity information menu drawing friends over its navigation row when an entity had more than 36 friends.
- Fixed clicks on empty bottom-row slots of list menus selecting an entry from the page.
- Fixed update checks offering the release of another edition: each edition now only sees its own tagged releases.

### Added
- Added a console diagnostics check that verifies statistics move correctly on ownership transfers.
- Added the edition model: `BlockProt Reloaded`, `BlockProt Reloaded Legacy` and `BlockProt Legacy`, shown in `/bp about`, the boot banner and `/bp debug`.
- Added the `.edition` marker in the plugin data folder. When the edition or the Minecraft version changes between starts, the plugin makes a backup named with both editions and logs it, and it warns when the change is a downgrade.
- Added a console diagnostics check that verifies the edition and its marker.

## Editions

BlockProt Reloaded covers Minecraft 1.21.7 and newer. BlockProt Reloaded Legacy (Minecraft 1.20.5 to 1.21.6) and BlockProt Legacy (Minecraft 1.18.2 to 1.20.4) are published separately and are announced with their first release. The [version guide](https://github.com/VictorGugug/BlockProt-Reloaded/blob/main/docs/READ_MEs/VERSION_GUIDE.md) explains which one to download and how to move between them.
