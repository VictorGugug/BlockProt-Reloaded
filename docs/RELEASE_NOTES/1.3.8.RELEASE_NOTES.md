# BlockProt Reloaded 1.3.8 Release Notes

Welcome to BlockProt Reloaded 1.3.8. This release raises the minimum Minecraft version to 1.21.1, opens a public developer API, moves the bundled translations to MiniMessage, and automates testing and upkeep so every future build is checked on real Paper and Folia servers.

## Highlights

- **Minecraft 1.21.1 Baseline**: 1.3.8 supports Minecraft 1.21.1 through 26.3. Servers on Minecraft 1.20.5 to 1.21 keep using BlockProt Reloaded 1.3.7; starting 1.3.8 on those versions shows a clear message and disables the plugin instead of failing later.
- **Public Developer API**: other plugins can check whether a block is protected, who owns it, who can access it, its friends, and entity protection, and can react to lock, unlock, and access events. The API is available through JitPack.
- **MiniMessage Translations**: the English and Spanish translations now use MiniMessage formatting, including exact hex colors. Translation files with legacy `&` and `§` codes keep working.
- **Real Server Testing in CI**: every change is now tested by starting real Paper and Folia servers with the plugin and running the full console diagnostics.
- **Weekly Maintenance Check**: a weekly job detects new Paper, Folia, and Purpur versions, tests the plugin on them, audits dependencies, and keeps a single report issue up to date.

## Changelog

### Added
- Added `isProtected`, `getOwner`, `canAccess`, `getFriends`, `isPublic`, `isLockable`, `isEntityProtected`, and `getEntityOwner` to `BlockProtAPI`.
- Added JitPack publishing for `blockprot-spigot` and `common`, with a Developer API section in the README.
- Added a console diagnostics check for the public API.
- Added a startup guard that disables the plugin with a translated message on Minecraft versions older than 1.21.1.
- Added a CI job that boots the newest supported Paper and Folia servers and fails on any diagnostics error.
- Added a weekly maintenance workflow and Dependabot updates for GitHub Actions.
- Added a daily platform check that confirms the latest stable release is live on GitHub, Modrinth, CurseForge, and Hangar, and publishes it wherever it is missing (CurseForge only after 72 hours, since new files wait for manual review).
- Added a post-publication check that confirms every release is live on each platform.

### Changed
- Merged the CI, publish, release, and maintenance workflows into a single `blockprot.yml` workflow with an operation selector.
- Raised the minimum supported Minecraft version to 1.21.1 and `api-version` to `1.21`.
- Converted `translations_en.yml` and `translations_es.yml` to MiniMessage; hex colors now render exactly instead of being approximated.
- Removed the 1.20.x particle and enchantment fallbacks and version checks.

### Fixed
- Fixed MiniMessage hex color tags not being recognized by the translation loader.
- Fixed the debug report headers showing outdated screen counts.
- Fixed the not-Paper startup warning still referring to the 1.3.6 end of Spigot support.
- Fixed the Hangar publish step skipping its JDK and Gradle setup.

## Status

- **BEDev**: pre-release builds of 1.3.8 are published on GitHub for testing before the stable release.
