# BlockProt Reloaded 1.3.7 Release Notes

Welcome to BlockProt Reloaded 1.3.7. This release adds Minecraft 26.3 support, makes the admin toolset usable from the server console, and completes the move of every scheduled task onto FoliaLib so Folia servers run the plugin without falling back to the Bukkit scheduler (ALSO DONE IN RECORD TIME!!: 1.3.7 took less time to build than any previous version of the plugin, and from 1.3.8 onward the plugin is expected to keep getting optimized while the time between releases keeps shrinking).

## Highlights

- **Minecraft 26.3 Support**: The Poplar wood set (doors, trapdoors, fence gates, signs, hanging signs, shelf, and chest boat) and the new Straw bed are protected out of the box through the existing block families. Verified on Paper 26.3.
- **Console Administration**: `/bp debug`, `/bp protdel`, and `/bp unlock` now work from the server console. Diagnostics run their block and entity checks at the world spawn when no player is online, so the full NBT and gameplay simulation suite no longer needs someone in-game.
- **Complete FoliaLib Scheduling**: The remaining Bukkit scheduler calls were replaced with region-aware FoliaLib scheduling. Work that touches blocks now runs on the region that owns each block, and player-facing work runs on the player's own thread.
- **Unified World Protection Deletion**: The chest GUI, the Paper dialog, and the console now share one deletion and undo engine that processes a world chunk by chunk on its owning region, spreads the work across ticks, and keeps an undo history per administrator.

## Changelog

### Added
- Added Minecraft 26.3 to the supported version range, covering `POPLAR_DOOR`, `POPLAR_TRAPDOOR`, `POPLAR_FENCE_GATE`, `POPLAR_SIGN`, `POPLAR_WALL_SIGN`, `POPLAR_HANGING_SIGN`, `POPLAR_WALL_HANGING_SIGN`, `POPLAR_SHELF`, `POPLAR_CHEST_BOAT`, and `STRAW_BED`.
- Added console execution for `/bp debug` (plain `/bp debug` now runs the suite), running NBT, entity, sub-handler, and player simulation checks at the main world spawn when no player is online.
- Added `/bp protdel <world> confirm` and `/bp protdel undo` for console use.
- Added console output for `/bp unlock <player>`, listing every block the player has locked.
- Added translation keys for the new console messages and for previously hardcoded texts in English and Spanish.

### Changed
- `/bp info <player>` now checks block ownership on each block's owning region before listing it, and reports when the player owns no blocks in both chat and dialog mode.
- `/bp transferall` now transfers each block on its owning region and updates statistics once all transfers complete.
- World protection deletion from the GUI, dialog, and console shares a single undo history; the GUI undo button restores the most recent deletion.
- World protection deletion without the database index now scans loaded chunks using the configured block families instead of a fixed material list.
- Player-only commands (`/bp settings`, `/bp disablehints`, `/bp lockables`, `/bp stats`) now reply with a clear message when run from the console instead of printing the command usage.
- Updated the documented support range to Paper 1.20.5 through 26.3.
- Reorganized dialog layouts: Block Settings shows the three protections on one row with Enable all and Disable all below, entity friend management uses the same `Prev | Search | Next` row as block friend management, and paged admin dialogs keep their navigation on its own row.

### Fixed
- Fixed the lock menu closing on Minecraft 26.3 when sneak-right-clicking a container with an empty main hand and a non-block item (such as a shield) in the off-hand. Since 26.3 the same click also fires an off-hand interaction, which opened the container on top of the menu; that interaction is now denied for the block only, so raising a shield still works and off-hand block placement is unaffected.
- Fixed revoked admin tiers returning to offline staff on their next join; `admins.yml` is now the only source used to resolve tiers and custom flags.
- Fixed world protection deletion and its undo using the Bukkit scheduler, which fails on Folia.
- Fixed the dialog-based world protection deletion querying the database on the main thread.
- Fixed friend search history heads being written to the inventory from an asynchronous thread.
- Fixed concurrent statistics updates from different Folia regions and the periodic save racing each other; all statistics access now shares one lock, and a failed save is retried on the next cycle.
- Fixed the global protected block counter drifting down on Folia when stale entries were checked from a region that does not own the block.
- Fixed the `SemanticVersion` diagnostic failing on BEDev and hotfix builds.
- Fixed console diagnostics reporting every inventory and dialog as uncovered.
- Fixed hardcoded English texts in `/bp tiers <player>`, the admin reload dialog, the custom flags menu, and the menu error message.
- Fixed the shadow JAR build warning about duplicate `kotlin_module` metadata.

### Repository and Governance
- The publish workflow detects development builds (`BEDev`, `SNAPSHOT`, `exp`) and publishes them to GitHub Releases only, as pre-releases, skipping Modrinth, CurseForge, and Hangar.
- The publish workflow summary now includes a copy-ready Discord announcement (post title, tag, GitHub link, and platform links).
- The publish workflow now detects existing CurseForge uploads through the public CFWidget API, preventing duplicate CurseForge files when a publication is re-run.
