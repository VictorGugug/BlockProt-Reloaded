# BlockProt Reloaded 1.4.0-hotfix Release Notes

> **Note:** As a targeted maintenance release, this hotfix does not include a release notes banner.

1.4.0-hotfix fixes the staff tier permissions of 1.4.0 and brings the documentation in line with what the plugin does. Servers that keep `admin_tiers.enabled: false`, the default, see no change in who can do what.

## Fixed

- **Admin hub checks each button**: with `admin_tiers.enabled: true`, any staff tier could open `/bp admin` and use every button in it, including the configuration editor, world protection deletion, reload, and staff role management. Each button of the hub now checks the tier of its action, in the chest menu, the Paper dialog, and the Bedrock form.
- **Lock menu on other players' blocks**: with admin tiers enabled, the Paper dialog and the Bedrock form gave every staff tier owner-level control over other players' blocks, while the chest menu did not. All three now require Tier 2, and Tier 2 can unlock those blocks as documented.
- **Tier 1 works as documented**: Tier 1 now opens `/bp info`, gets a read-only lock menu on other players' blocks with the block info and the audit log, and can teleport from admin block lists.
- **Startup warning**: the warning shown on Spigot and CraftBukkit no longer says support ends in 1.3.6. They are not supported.

## Documentation

- The [README](https://github.com/VictorGugug/BlockProt-Reloaded/blob/main/README.md), the [admin guide](https://github.com/VictorGugug/BlockProt-Reloaded/blob/main/docs/READ_MEs/ADMIN_GUIDE.md), the [player guide](https://github.com/VictorGugug/BlockProt-Reloaded/blob/main/docs/READ_MEs/PLAYER_GUIDE.md), and the download page descriptions now describe commands, permissions, friend levels, staff tiers, and the optional MySQL index as the plugin implements them.
- Timed access and the ImageFrame integration were listed as features but never existed. They are no longer mentioned.

## Testing

- Minecraft 26.1 is now tested on its newest server build, 26.1.2. Earlier test runs skipped it because no server software publishes a build named 26.1.
